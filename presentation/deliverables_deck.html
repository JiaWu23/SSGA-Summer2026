04M1 · the primary side model

Selection, not sizing

Inference

score = 0.45·mom + 0.25·trend
       + 0.20·macro − 0.10·risk

Each Friday, rank the 7 sleeves by score and go long the top 3 (allocation_mode: top_k). Long-only in the production sleeve.

Training
  • Rule-based (default): no fit — the four weights are an economic prior, not an optimized result.
  • Optional ML variant fits logistic on m1_target ∈ {−1,0,+1} = sign of forward 4-week return vs ±0.5%.
  • Conviction sizing is off — the score selects; it does not size.
Known weakness — flagged, not hidden

The weights were never experimentally justified. The existing grid search tuned train window and threshold — not factor weights. The one tuning attempt (IC-proportional) was walk-forward-rejected. And momentum & trend are near-collinear, so a 45/25 split puts ~70% of the weight on one underlying signal.

0.78corr(momentum, trend), n=5523
0.09corr(macro, momentum) — the only diversifier

→ Fix (Axis A): merge momentum + trend into a single technical factor, then walk-forward-sweep technical / macro / risk weights. This is the SSGA mentor's own suggestion, now quantified.

05Meta-labeling, preciselyXuesong's five questions

M2 judges M1's trade — it does not trade

Training sample

Only asset-weeks where M1_signal ≠ 0 — i.e. the trades M1 actually proposed. M2 never sees flat weeks.

Meta-label construction

meta_label = 1 if sign(M1)·r₄w > cost, else 0. A binary “did this trade pay?” — not a −1/+1 direction.

Horizon & threshold

4-week forward window = the weekly-rebalance holding period; ±0.5% plus a 0.1% cost hurdle embeds a minimal edge above noise and frictions.

Features & why

52 features: momentum/trend/vol, cross-asset dispersion, macro regime, M1 context. Economically: when does a momentum trade fail? — in stress, crowding, adverse regime.

Calibration · validation · interpretation
0.589test AUC-ROC (full sample)
≈0.49mean AUC across walk-forward folds
0.84recall @ threshold 0.55
60.8%base rate (M1 trades that pay)

Sigmoid-calibrated; validated on the out-of-sample window only. Honest read: mean P on winners (0.577) ≈ on losers (0.574) — M2 barely separates. At recall ≈ 1 it approves nearly every trade, so its value is a soft input to M3 sizing, not a hard filter.

06M3 · bet sizing

Three rules map probability → bet fraction

Binary

f = 1[p ≥ T]

All-or-nothing at T=0.55. At recall≈1 it approves ~everything → ≈ M1-only.

Linear

f = max(0, 2p−1)

Very defensive; high Sharpe but starves return. A drawdown tool.

ECDF · production

f = rank_train(p)

Rank-based on the train distribution. Best risk-adjusted of the three — but see Deliverable 4.

The mental model: M1 = opportunity selector · M2 = trade-quality probability · M3 = capital deployment · Portfolio = risk-budget enforcement. The three M3 rules differ mostly in how much they deploy — which is why their drawdowns differ, and why that difference must be controlled before it is called skill.

09Deliverable 4 · Genuine vs mechanicalthe M3 question

Does M3 pick better trades, or just deploy less?

  • ① Constant-haircut control. Scale M1-only by a fixed factor to ECDF's average gross (~52%). If ECDF ≈ this dumb de-risk → M3 is a volatility knob, not selection.
  • ② Vol-matched. Scale every variant to the same 10% ex-ante vol, then compare. Any surviving edge is not mechanical.
  • ③ M3_size information coefficient. Spearman(M3_size, realized trade PnL). If ≈ 0, M3 does not distinguish strong from weak candidates — full stop.
  • ④ Drawdown decomposition. ΔDD = exposure effect + selection effect. Report both, not the raw gap.

10Broader experimentation · macrosample-controlled

Is macro the lever? A controlled test says no

Method — the control that makes it clean

Download all 7 macro series for every variant so the sample window is byte-identical; vary only which macro signals feed the model (excluded signals zeroed, not dropped). Any Sharpe difference is then the macro signal — not a shifted sample.

12Honest verdict & next phase

A rigorous baseline, not a conclusion

What holds up

  • M1-only is the robust core: ≈ EW return, ~half the drawdown, higher Sharpe.
  • The validation discipline — walk-forward, deflated Sharpe, sample-controlled ablations — is the real asset.

What is unproven

  • M2/M3 meta-labeling does not beat M1-only out-of-sample (1/6 folds).
  • ECDF's drawdown edge may be mechanical — D4's exposure-matched tests decide it.
